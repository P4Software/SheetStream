SheetStream web sample

Excel downloads from an ASP.NET Core minimal API, streamed row by row.

Each button below hits an endpoint that returns ExcelResults.Excel(...). The workbook is written while the data is being read, so memory stays flat no matter how many rows you ask for, and the browser receives a normal file download with an exact size.

Streamed table export

GET /orders.xlsx?rows=N pulls orders from a simulated async database through LoadFromAsyncEnumerable into a styled Excel table: bold header, number and date formats, filter buttons, frozen header row and a live SUM formula. Try 500,000 rows to see that it just keeps going.

Summary with charts

GET /report.xlsx shows the other way to build a sheet: random-access Cells[...] for a small revenue-by-month table with totals, plus a column chart and a line chart that read those cells.
